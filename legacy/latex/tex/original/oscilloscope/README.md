# 阴极射线示波器原资料

`page-01.png` 至 `page-11.png` 按用户提供的顺序保存教材截图。
当前 `tex/official/` 无该实验的专用官方报告，所以依据这些教材资料整理，统一载入源自 `tex/物理实验报告模板.tex` 的公共版式。

- 保留示波器扫描、触发、峰峰值/周期及李萨如测频的核心原理。
- 用 TeX/TikZ 重绘简化框图和四种理想频率比，示意图不带教材水印，不代表实测观察。
- 七组波形依教材顺序为正锯齿、反锯齿、脉冲、半波、正弦、方波、三角波；电压和周期表分开排版，以提高可读性。
- 李萨如记录五组，`nx` 是水平线切点数，`ny` 是垂直线切点数，`fy = fx * nx / ny`；五组及正弦波周期法须测同一固定频率信号。
- 校准信号按教材取 0.5 Vpp、1 kHz，并使用 X1；校准偏差不自动修正后续读数。
- 测量值和计算结果在模板中留空；讨论、四道思考题和结论保留，结论中的数值由后端填入。未输入的仪器误差不被推测。
- 完整报告含封面、四页正文及原始记录页，基础为 6 页，最多附两张原始记录图片（7 页）。

模板正文生成源：`scripts/oscilloscope_template.py`；运行时模板：`tex/templates/oscilloscope.tex`；独立压缩包：`tex/zipped/oscilloscope.zip`。
验证样例数据位于 `scripts/verify_reports.py`，属于演示输入，不能用作真实实验记录。
