# 0004：文档职责分离

状态：已接受，2026-10-31。

背景：原文档混合当前规则、操作过程、历史验收和迁移方案，透镜方向等规则已有重复或过时描述。

决定：`docs/README.md` 作为统一入口；`specs/` 保存精简的当前事实与契约，`guides/` 保存操作流程，`adrs/` 保存重要取舍，`plans/` 保存实施与验收，`archive/` 保存历史上下文。每个当前规则只定义一次，其他文档链接引用。

理由：保留历史依据，同时使维护者能判断当前应遵守哪份规则。将测试通过记录放入有日期的计划，避免把过往环境结论当作当前保证。

影响：行为修改必须同步 specs，重要决策新增 ADR，计划完成需填写实际结果与未验证项。布局约束进入根 [AGENTS.md](../../AGENTS.md)，旧路径的活跃链接随迁移修复。
