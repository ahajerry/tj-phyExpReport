# 0006：固定原字体并对齐 LaTeX 版式

状态：已接受，2026-10-31。替代 [0002](0002-typst-rendering.md) 中允许字体与版式宽泛变化的部分。

背景：迁移后的 Noto/Libertinus 字体、默认段距和等宽网格使报告外观明显偏离原 LaTeX。用户要求字体、间距、样式尽可能一致，并明确选择将原字体及许可证保存在仓库。

决定：保存与原镜像一致的 Fandol、Latin Modern OpenType 文件，以哈希固定版本。共享版式按 TeX 物理单位恢复；每种实验保留原表格、标题与图注差异。保留 Typst 原生可编辑图形和 Go 数值计算，不通过整页截图模拟旧报告。对合成 PDF 增加字体、页数和几何回归，并保留人工逐页检查；编译器的字体或布局警告不得被当成成功而发布产物。

理由：只保留约 18 MB 字体即可恢复原字形，无需重新安装 TeX。仓库保存字体避免下载源变化或系统同名字体影响构建；构建时下载固定字体会增加外部依赖。Latin Modern Math 可供 Typst 使用，并接近原 Computer Modern；两种数学引擎和自动断行仍有差异。

影响：仓库增大，但镜像不再安装整套 Noto CJK；本地与 Docker 使用同一字体目录。源码 ZIP 继续不附带字体，说明改为取得仓库固定字体后离线编译。字体和模板变化必须重新验收，页数相同不能替代视觉检查。当前参数只在 [报告契约](../specs/reports.md) 定义，实施证据见 [计划](../plans/2026-10-31-typst-layout-parity.md)。
