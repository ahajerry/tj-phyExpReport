# 0005：固定 pnpm 与唯一锁文件

状态：已接受；2026-10-31 追认现有约束，用户确认继续沿用。

背景：仓库已经指定 pnpm 11.28.5。锁文件固定依赖解析结果，但不同包管理器版本仍可能使用不同的锁文件格式、peer dependency 解析、安装布局或依赖构建脚本策略，导致本地和容器行为不一致。

决定：以 `package.json#packageManager` 指定的精确版本运行 pnpm，匹配 engines；只保留 pnpm 锁文件。依赖未变化时冻结安装，升级工具版本作为一次明确的维护变更验证。

理由：固定的是可复现的工具基线，并非声称该版本永远最好。Typst 不要求这个 pnpm 版本；本次沿用约束能减少与排版迁移无关的变量。允许随验证升级，比永久禁止升级或所有机器自行选择版本更合适。

影响：开发、CI 和 Docker 需使用同版本；升级时同步配置、维护约束与说明，并验证冻结安装和镜像构建。具体操作见 [开发指南](../guides/development.md)。
