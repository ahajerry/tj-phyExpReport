# 0007 远程 MCP 复用报告队列并隔离调用者

状态：已接受。

DSH 用户需要上传实验数据、生成报告并取得可本地编辑的文件。网站现有匿名 Cookie 面向浏览器，报告队列对每个数据目录实行单实例锁。

在 `reportd` 中挂载无状态 Streamable HTTP MCP。为受控的多用户部署使用可撤销的个人令牌，令牌轮换保持主体 ID。继续使用同一队列和渲染进程，调用者的网页会话不参与身份映射。文件通过同源的鉴权 HTTP 端点上传和下载。MCP 调用只携带结构化数据与文件引用，避免大文件占用模型上下文。

运营方负责令牌发放和 HTTPS。SQLite 增加事务内的幂等记录以支持断线重试。内存暂存有固定上限且随重启丢弃，已提交报告仍由原队列持久化。具体行为见 [MCP 契约](../specs/mcp.md)。
