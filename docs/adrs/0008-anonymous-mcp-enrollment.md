# 0008 MCP 访客自助开通与独立队列额度

状态：已接受。扩展 [0007](0007-remote-report-mcp.md) 的个人凭据体系。

固定服务站点为 `https://lab.tongji.sh` 的 DSH 用户需要直接生成报告。逐人登记令牌会增加首次使用的步骤。选择让 Skill 在本地生成并保存随机令牌，服务端登记摘要并按个人凭据隔离任务。以同一令牌重试开通，可以恢复网络中断的请求。管理员发放的凭据与网页匿名 Cookie 沿用各自的身份。

站点可启用访客开通。访客不需要账号，丢失本地凭据时无法恢复其报告。分别限制开通、每人及全局的生成额度，减少匿名流量占用现有队列。详见 [MCP 契约](../specs/mcp.md)。
