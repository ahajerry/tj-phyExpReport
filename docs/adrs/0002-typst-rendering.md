# 0002：Typst 原生模板与 Go 计算边界

状态：已接受，2026-10-31。

背景：XeLaTeX 与宏包使镜像和部署较重；用户要求迁移 Typst，并希望下载的正文和图表可以编辑。

决定：用固定 Typst 编译器、八种原生模板和共享版式替换生产 TeX；图表使用标准库绘制，数据通过 JSON 传入。Go 继续计算物理结果与图点。中文字体由运行镜像安装；源码包仅提供字体安装说明。允许字体、换行和分页合理变化。

选择理由：原生模板便于编辑；直接生成可读 Typst 比嵌入整页图片保留更多可维护性。静态图表截图无法满足编辑要求，在线图表包会增加离线编译依赖。把物理计算再实现于 Typst 会引入第二套公式与修约行为，因此不采用。

影响：模板需要逐实验移植与视觉验收；源码离线编译前须安装同版本工具和字体。生产切换允许停机，使用新数据卷，不做旧 PDF/队列迁移。旧模板、教材参考和专用 Python 工具冻结在 `legacy/latex/`，不参与当前生成流程。现行细节见 [报告契约](../specs/reports.md)。
