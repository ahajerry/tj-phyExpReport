# 报告与源码契约

## 输入与排版

唯一当前模板为 `typst/templates/{experimentId}.typ`，共享 `base.typ`、`charts.typ`、图片和校徽。固定 Typst **0.15.1**，生产镜像同时固定官方工具镜像摘要。排版以冻结的 LaTeX 模板和合成基准 PDF 为依据，尽可能保持字体、字号、间距、表格与插图样式。

字体固定在 [`typst/fonts/`](../../typst/fonts/README.md)，以 `SHA256SUMS` 校验文件：中文正文 FandolSong（常规/粗体），一级标题与封面 FandolHei（常规），西文 Latin Modern Roman，表格使用其 9 点光学版本，封面英文 Latin Modern Roman 12 粗体，数学 Latin Modern Math。后者延续 Computer Modern 字形，但 OpenType 数学布局与原 TeX 数学引擎仍有细微差异。字体随仓库和镜像保存，不随报告 ZIP 分发；更新必须重新进行版式验收。

共享版式使用 A4，左右边距 3.175 cm、上下 2.54 cm；字号按 TeX 点（1/72.27 英寸）换算。正文 10.5 点，基线间距 20 点，段后附加 2 点；声速使用 18 点基线、0 段后间距，杨氏模量也使用 0 段后间距。一级标题为常规黑体，二级通常为粗体宋体，声速二级为黑体。封面、装订线、页眉线、页码延续旧模板。表格按实验保留自然列宽、固定列宽、合并单元格、三线表或网格线；图注随图排版，曲线使用框内图例及原生矢量连接线。避免页尾孤立标题，受迫振动两幅曲线放在同一页。

标准合成样本检查原字体嵌入、页数、封面/正文标题坐标及纸张边界，并逐页对照。数学字距、自动换行和任意变长输入的分页不保证逐像素相同；不得把这些差异作为改用其他字体或统一覆盖实验特有样式的理由。

Go 负责全部物理计算、单位换算及修约。适配器将 `fields`（结果/读数文本）、`data`（归一化读数）、`plots`（坐标字符串对）、`tables`、`images` 与标题序列化到 `data.json`。用户文字经 JSON 读取后作为文本显示，不拼接到 Typst 代码，不调用 eval。缺失历史原始读数保持空白，不反推或伪造记录。

`charts.typ` 使用原生曲线、标记、表格和布局，不依赖在线包或预先生成的图表截图。坐标由 Go 计算，Typst 仅进行绘图比例、刻度和示意图计算；散点、拟合线、A/B 标记、半功率线、相位和李萨如图形可在源码中编辑。修改 JSON 读数不触发物理重算。

图片由 ImageMagick/libheif 读取首帧、校正方向、白色背景去透明，缩小到 3000×3600 范围，输出质量 90 的 JPEG。源码包含 PDF 实际使用的转换图，原上传文件仍只保存在服务器原图目录。

## 编译与快照

每次任务使用独立工作目录，检查编译器版本及上述六个字体族，指定字体目录时忽略系统字体。执行一次 `typst compile`，固定根目录、一个编译线程、创建时间戳 0；单次编译超时 120 秒，工具日志最多保留尾部 16000 字节，取消时终止进程组。编译根目录不能读取上级文件。即使编译器返回成功，若有警告（例如字体缺失或布局不收敛）也判定失败，不发布 PDF 或源码。

ZIP 保存实际编译时的输入快照：

| 文件 | 内容 |
| --- | --- |
| `report.typ` | 本实验正文 |
| `base.typ`、`charts.typ` | 共享版式与原生图表 |
| `data.json` | 本次文字、读数、结果、图点及图片引用 |
| `tongji_logo.jpeg`、被引用的 `figures/` | 静态资源 |
| `original_XX.jpg` | 本次实际使用的上传图片，可为空 |
| `README.md` | 编译命令、字体安装、数据编辑边界 |

只打包显式输入列表，路径为相对路径，拒绝符号链接；不包含字体、其他实验模板、PDF、日志、原始 CSV/XLSX 或服务器路径。内容可能包含用户填写的姓名、学号和实验记录。两个产物都归档成功才发布，源码下载与 PDF 使用相同鉴权。后续模板修改不影响已保存的源码。

使用相同编译器和字体文件可复现排版；在固定镜像中的断网重编译测试比较 PDF SHA-256。不同字体版本或运行环境不承诺字节一致。安装方法见 [源码指南](../guides/typst-source.md)。
