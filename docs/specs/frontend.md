# 前端契约

当前只启用 [字段目录](fields.md) 中的八项实验。`structured-experiments.ts` 定义录入配置，`experiments.ts` 提供导航，两者 ID 必须一致；实验页由 `StructuredExperimentPage` 渲染，`App.tsx` 提供共享外壳、关于页和报告页。无效及已归档的实验地址 replace 跳转首页。

读数与参数以字符串保存在表单和浏览器缓存，保留末尾零。JSON、仪器表格导入后可编辑，提交使用最终表单值；缓存升级不虚构原始读数。字段单位及计算约束分别由 [fields](fields.md)、[experiments](experiments.md) 定义。

报告页按 API 状态轮询并展示进度、阶段、失败原因和历史。仅 done 状态展示并排下载入口：主按钮“下载 PDF”，`variant="secondary"` 的“下载 Typst 源码”按钮；窄屏允许换行。按钮为原生链接，分别指向 PDF 和源码接口，文件名带报告标题。旁边说明源码为 ZIP、需安装 Typst 和中文字体。历史条目选择后沿用相同下载区域。

下载不重新提交任务；前端可见性不替代服务端鉴权。上传、Cookie、额度和状态的具体契约见 [API](api.md)。页面不显示固定渲染耗时或“两次 LaTeX 编译”等旧说明。

页面默认使用本地 Noto Sans SC，数值/代码使用 JetBrains Mono；主题采用语义颜色变量。小于 768px 使用侧栏抽屉，链接点击后关闭；支持键盘焦点、状态提示和减少动态效果。首页字符动画与普通页面样式隔离。组件位置及修改流程见 [前端维护指南](../guides/frontend-ui.md)。

## 关于页与文章排版

八个实验录入页标题旁均提供“查看资料”链接，跳转至 `/materials#materials-实验ID`。资料页挂载或锚点变化后滚动并聚焦对应标题，留出固定顶栏空间；直接访问无有效锚点的资料页回到顶部。暂无指标的实验仍可定位至保留的标题。

资料页每个实验标题下提供“复制”按钮，仅将指标文字按表格顺序以换行连接写入剪贴板，不包含标题、类别、编号或 Markdown 格式符。缺少资料时按钮禁用；复制成功显示反馈，剪贴板访问失败时提示检查权限并重试。

“资料”页位于 `/materials`，从侧栏导航进入，复用文章容器。实验标题和顺序直接取自 `experimentItems`，与侧栏一致。每个有资料的实验直接展示“指标 / 类别”两列 Table，不折叠；缺少资料的实验仅保留标题。当前收录七个实验的三级指标，扭摆实验暂缺。数据来自用户提供的评价截图，仅收录指标文本和类别，不展示个人评分、系数、权重、得分、状态或分析报告；重复截图与示波器连续截图中的重叠行只收录一次，不合并不同类别中的同名指标。

关于页内容位于 `App.tsx`，由 `LabAbout` 输出 `<article className="about-prose">`。正文排版是 `src/index.css` 中的手写作用域 CSS，不依赖 Tailwind Typography 的 `prose` 类；颜色和字体继承全站主题。

| 元素 | 当前样式 |
| --- | --- |
| 正文容器 | 最大宽度 760px、水平居中，上下 padding 为 24px / 64px；字号 18px、行高 1.85 |
| 标题 | h1 为 `clamp(30px, 4vw, 42px)`；h2 为 27px，顶部间距 48px；h3 为 21px |
| 段落与列表 | 上下 margin 为 20px；列表项保留缩进与项目符号 |
| 链接与行内代码 | 普通链接带下划线，按钮链接除外；行内代码有主题背景和 5px 圆角 |
| 窄屏 | 600px 及以下正文 17px、顶部 padding 12px；h2 为 24px，顶部间距 36px |

`content-blocks.css` 维护 CodeBlock、Callout 和 ContributorCredits 的样式：代码块与提示框使用 18px 圆角，颜色跟随主题；致谢卡片默认双列，600px 及以下单列。Callout 支持独立提示配色。部分提示框和致谢选择器依赖 `.about-prose`，迁移容器类名时需同步处理。

该排版适用于介绍、帮助、教程、更新日志和实验原理等文章内容。目前没有完整定义文章表格、引用块及通用图片样式。作用域内的标题、段落、列表和代码都会受到影响，不能假设包裹复杂表单后仍保持原有控件布局。
