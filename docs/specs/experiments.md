# 实验与计算

所有计算位于 `server/internal/experiments`。表单字段、输入单位和默认值只在 [字段目录](fields.md) 定义；报告章节及图表要求见 [报告契约](reports.md)。本次更换排版引擎，不改变物理计算规则。

## 共同规则

JSON 数字和字符串直接解析为十进制，保留原始读数文本。代数使用 shopspring/decimal，除法保留 60 位小数；平方根使用 256 位 big.Float 后转回十进制，log/atan2 边界沿用 float64 定义。大小与指数有界，错误不能当作零继续计算。

先完整计算，再在输出末端半偶修约。一般不确定度首位 1/2 留两位，否则一位，结果末位对齐不确定度；过程字段一般六位有效数字。科学计数法保留相应指数与必要尾零；原始读数不按结果精度改写。扭摆 K/I 的例外见下文。

普通小数与 `e/E` 文本保持原样。`5.00×10⁻²`、`5.00×10^-2` 等形式转换为 `5.00e-2`，乘号接受 ×/x/X/*；不接受单位或任意算式，不通过表达式求值器解析。零、空白和尾部未使用行是否有效由各实验决定。

## 八种实验

| ID | 计算与校验边界 |
| --- | --- |
| `oscilloscope` | 方波/正弦波/三角波/半波四行；峰峰值为探头倍数×电压档位×跨度，周期为时基×跨度；ms 对应 kHz；李萨如 `fy=nx/ny×fx`，保留约分比及四次测频统计 |
| `speed-of-sound` | 共振/相位各 20 个有效位置，前后十项逐差求波长，再求声速、室温理论值、频率和卡尺误差传播；无 parameters 的旧输入仍能给出波长，缺少信息不伪造 |
| `heat-capacity-ratio` | 五组直径末减初、100T 除以 100，计算 γ 及完整不确定度；新旧数据字段不得混用，详细常量见下文 |
| `millikan` | 连续 3–8 颗，每颗四次平衡电压和下降时间；各自求均值，计算电荷、整数倍数及三种估计；允许容量尾部全空，拒绝部分缺失或中间断组 |
| `moment-of-inertia` | 载物盘 20 周期、规则物体 10 周期、滑块 5 周期；三次计时；质量 kg、尺寸 cm 转内部 g/mm；圆柱/圆筒扣盘，球/杆/滑块组合不扣盘 |
| `young-modulus` | 十级加卸载均值、五级逐差、五组净直径、图解斜率及误差预算；预载不计作用质量；L/D/K 仪器误差为 0.1/0.2/0.02 cm；旧净直径输入兼容零初值 |
| `forced-vibration` | 自由/阻尼/受迫组数独立并动态匹配；10T 只除一次；同振幅自由周期插值、负相位、半功率交点，范围外不外推；保留完整图点及变长读数 |
| `focal-length` | 三方法各三组原始位置，仅接受当前九列，拒绝旧距离/凹透镜格式；位置差取绝对值，支持正反向与零/负坐标；透镜必须在两屏之间，共轭大像位置须更靠近物屏 |

透镜用 `f=uv/(u+v)`、`f=(L²−D²)/(4L)`、`f=|auto_lens−auto_object|`；输出各方法均值和 A 类标准不确定度。旧 `position_direction` 仅接受 ±1，省略补 1，但不影响计算。每组方向可独立；前两次放大、第三次缩小是表单操作提示，不额外校验放大倍率。

## 空气比热容比

当前输入的直径仪器误差为 0.004 mm，按均匀分布除以 √3；周期 B 类标准不确定度直接取 0.001 s，容积标准不确定度直接取 0.002 L，后两者不除以 √3。容器压强不确定度近似采用大气压不确定度，g=9.794 m/s²，理论 γ=1.402。内部换算到 SI，最后修约。

旧 `diameter`、`period` 各五项及原十参数（含 diameter_zero_mm、diameter_error_mm、period_error_s、volume_error_l）继续按旧修正与不确定度规则处理。旧初读数为空，末读数显示净直径并说明来源，100T 由旧周期换算；浏览器缓存迁移要求补填实际初读数，不把零当作实际测量。

## 密立根油滴

按讲义式 8.3.19，`q=0.928×10⁻¹⁴/{U[t(1+0.0226√t)]^(3/2)}` C，其中 t、U 是同滴四次均值。时间与修正项共同取 3/2 次方。公认元电荷为 1.602176634×10⁻¹⁹ C，用于辅助确定整数 n；固定 n 的模糊统计估计与过原点最小二乘一致，不能作为独立验证。图解采用带截距拟合。

反向验证的 e 为各 q/n 的均值；反向验证与最小二乘均按讲义 `Ue=t√[Σ(q/n−e)²/(m(m−1))]` 输出 95% 扩展不确定度。m=3–8 的 t 因子分别为 4.303、3.182、2.776、2.571、2.447、2.365。旧标准不确定度字段保留，图解斜率误差仍为拟合标准不确定度。

讲义常数为 d=5×10⁻³ m、l=1.6×10⁻³ m、η=1.83×10⁻⁵ kg/(m·s)、ρ₁=981 kg/m³、ρ₂=1.2928 kg/m³、g=9.794 m/s²、b=8.23×10⁻³ m·Pa、p=1.01325×10⁵ Pa，计算沿用其近似系数 k=0.928×10⁻¹⁴、k′=0.0226。讲义正文 b=8.22×10⁻³ 与参数表不同、式 8.3.21 用公认值定义偏差的历史记法保留；实际计算以上述规则为准。

独立高精度参考 `(t,U,q)` 为 `(4,100,1.0855726362588707148×10⁻¹⁷)`、`(16,200,6.3673576172547516812×10⁻¹⁹)`、`(25,300,2.1075309540952215386×10⁻¹⁹)`，对应固定参考样本，不能用旧漏掉 √t 的结果回填。

## 扭摆惯量与末端修约

平行轴理论为 `I′=I₄+2mx²+I₅`：I₄ 是未修约的细杆实测惯量，m 是两滑块平均质量，I₅ 是用户提供的两滑块绕质心轴总惯量。讲义展示 I₅ 几何公式，但不能强制使用讲义示例值。

独立样本 I₁′=0.00125 kg·m²、T₀=1 s、T₁=2 s、T₄=5 s，故 I₄=0.00125×25/3；滑块质量 0.1/0.2 kg、I₅=0.0001 kg·m²、x=5 cm 时理论组合惯量为 0.011266666… kg·m²。计时不确定度只包含重复计时贡献，标定圆柱的计时项相消；缺失三次尺寸的旧输入不补造读数。

仅本实验最终 K 和全部惯量留四位有效数字，百分差留两位，零误差显示 0。例如 0.00013→0.0001300、27.81%→28%、0.0786443%→0.079%、386.1%→390%。后续计算和图点使用未修约值，因此显示相同的理论/实验惯量仍可能有非零百分差。不改变周期、尺寸、质量或其他实验的精度策略。

## 仪器导入

- 油滴：UTF-8/BOM 或 GB18030 CSV，识别平衡电压和时间表头，每滴四行；保留当前电压、仪器电荷量与空白，不用计算结果补填仪器列。兼容旧六列记录。
- 扭摆：读取 XLSX 固定单元格，保留三次尺寸、原始总计时及两滑块惯量，并完成单位换算。
- 波尔共振：只读“学生实验数据”工作表，支持移动列、合并单元格旁的值、自由周期续列和独立数量的阻尼/受迫记录；优先测量表，拒绝不完整行或不连续序号。

XLSX 只读取 ZIP/XML 的值和已有公式缓存，不执行公式、不访问外部链接。未保存计算缓存时需在表格软件中重算并保存。导入及附件限额见 [API](api.md)。

数值规则变化须更新 `server/testdata/calculations.json`、相关独立边界测试与本文；模板迁移不能以放宽数值断言掩盖差异。
