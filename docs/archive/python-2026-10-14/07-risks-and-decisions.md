B09 的一个具体路径是 `/import-table` 接受含非空 sourceTables 的 JSON 后，直接进入 `editable_import`，该函数索引 data/parameters 和多层 rows。缺字段可抛 KeyError，而 HTTP 层没有通用结构错误转换。修复应建立明确公共输入结构，不能仅增加一个吞掉所有异常的 except。

## 需要修正文档的差异

- 根 README 说模板目录只读，声速实现仍会写入。
- 根 README 对油滴、扭摆附图能力和表格必须上传的描述，与现有可编辑输入页面不完全一致。
- 根 README 的 Git 初始化/分支说明是历史维护建议，不应在已经克隆的仓库照做 `git init`。
- `scripts/report_index.py` 在 README 中描述，但当前分发仓库无该文件且 gitignore 明确忽略；不能把它写入可用维护工具清单。
- 公共版式、声速独立版式、模板生成源和导出归档有多份内容，不能只凭 README 判断所有报告版式完全统一。
