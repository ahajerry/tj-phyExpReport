# Typst 与 LaTeX 版式对齐

状态：已实施并验收（2026-11-01），提交分支 `refactor-typst`。计划始于 2026-10-31，用户要求尽可能保留原 LaTeX 的字体、间距和样式；本计划收紧迁移时允许的版式差异。

## 基准与范围

- 以迁移前 `6a4ac04` 的合成数据生成的八种 LaTeX PDF 和 `legacy/latex/tex/templates/` 为基准，不读取用户数据，不修改历史模板。
- 已定位：字体替换、标题字重、TeX/Typst 点单位差异、段落和封面行距、等宽表格及公式转换造成明显偏差。
- 用户选择将约 18 MB 原字体和许可证固定在仓库；下载源码 ZIP 仍不附带字体。
- 保持 Go 计算、可编辑原生图表、源码快照、断网编译和无 TeX/Python 的生产运行方式。

## 阶段清单

- [x] 固定 Fandol 宋体/黑体、Latin Modern 正文/数学字体及校验清单，统一本地和容器字体检查。
- [x] 恢复共享封面、标题层级、正文基线、段距、页眉页脚、装订线、公式和表格样式。
- [x] 对照八种实验的特有字号、表格列宽、插图说明、曲线和分页；检查长表与可变行数。
- [x] 输出合成样本的前后对照、PDF 字体和页数检查，逐页目视复核八种基础报告共 63 页。
- [x] 运行后端、43 组合成样本的真实编译、镜像构建与 Docker 冒烟（含源码离线重编译）。
- [x] 更新 specs、指南和 ADR，在 `refactor-typst` 提交。

## 实施结果

字体集合单独提交为 `3cf90f7`，保留上游许可证、说明和字体清单。源码 ZIP 中的说明引用这个固定提交，避免分支或字体版本变化影响旧报告。生产构建只复制字体并校验哈希，不下载字体，不引入 TeX/Python。

共享模板按原 TeX 的物理尺寸恢复封面和正文。逐实验恢复下划线读数、表格行距与列宽、三线表及内网格、合并单元格、图注和曲线。修复了封面长实验名换行、图注被识别为编号列表、斜线被错误转换为分式，以及原始记录上标触发字体回退的问题。

标题、图表与结果组使用原生不可拆分块和粘连规则控制分页。曾尝试按标题当前位置决定分页，真实编译发现会导致位置反复变化、布局不收敛，已移除。后端将编译警告视为失败，并以真实编译器的缺失字体警告验证不会发布产物；Docker 源码复编译也要求零警告。

当前契约见 [报告 spec](../specs/reports.md)，取舍见 [ADR 0006](../adrs/0006-latex-layout-parity.md)。

## 剩余差异与未验证项

- Latin Modern Math 的 OpenType 数学布局与 TeX 不同，根号、上下标、积分/求和等复杂公式的字距和行高仍有差异。
- 自动断行、部分公式和段落的跨页位置并非逐像素一致；相同总页数不能证明逐页内容位置完全相同。此次已人工检查基础报告的表格、图注、曲线和主要布局。
- 可变行数等扩展样本完成真实编译和自动边界检查，没有对每一种输入组合进行人工视觉验收。
- 本次未在 Windows、macOS 或 ARM64 上执行验收，也未使用用户真实报告；字体和编译器版本一致不等于不同平台承诺 PDF 字节一致。
