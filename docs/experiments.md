# 实验与计算

八种实验保留原有 LaTeX 模板与前端表单。具体字段、单位和初始数量见 [字段目录](fields.md)；代码位于 `server/internal/experiments`。

| 实验 | 实现与保留规则 |
| --- | --- |
| 声速测定 | 共振/相位各 20 个有效位置，前后十项逐差求波长，室温理论声速、频率与卡尺误差传播；旧缺少 parameters 的任务仍可生成波长结果 |
| 空气比热容比 | 直径零点修正、压力修正、振动周期均值和不确定度传播 |
| 密立根油滴 | 3–8 颗，每颗 4 次计时；反算法、图解法和最小二乘元电荷估计；保留原始 32 行可编辑表和尾部空白规则 |
| 扭摆转动惯量 | 载物盘 20 周期，其他物体 10 周期，滑块 5 周期；圆柱/圆筒扣盘，球/杆/滑块组合不扣盘；保留 kg/cm 到内部 g/mm 的转换 |
| 杨氏模量 | 10 级加载/卸载均值、5 级逐差、净直径、图解斜率及完整误差预算；旧净直径输入兼容零初值 |
| 波尔共振 | 自由/阻尼/受迫组数动态匹配；10T 只除一次；同振幅自由周期插值、负相位、半功率交点，不做范围外外推；动态展开报告表格 |
| 透镜焦距 | 成像法、共轭法、自准直法；凹透镜允许整组缺省或空白，部分缺失拒绝；未测时删除对应报告段落 |
| 示波器 | 方波/正弦波/三角波/半波四行；ms 到 Hz，李萨如 nx/ny 方向与约分；最多附两张图片 |

## 数值与显示

JSON 数字和字符串均直接解析十进制，保留原始读数文本。代数使用 `shopspring/decimal`，除法保留 60 位小数；平方根使用 256 位 big.Float 后转回十进制。log/atan2 边界沿用原实现的 float64 定义。数值大小与指数有界，错误不转成零继续计算。

此精度策略比旧 Python Decimal 的 28 位上下文更高，不宣称任意输入逐中间位一致。合成参考样本比较最终数值和图点；临界有效数字使用独立测试。实验参考常数和公式未借重写修改。

不确定度首位为 1/2 保留两位，否则一位；结果末位对齐不确定度。最终输出使用半偶舍入；先完成计算再修约。很大/很小结果可使用共享科学计数指数；原始表格读数不按结果精度改写。一般过程字段采用六位有效数字，过程字段和零不确定度结果的尾零可能与 Python 的文本表示不同。

## 导入

- 油滴：UTF-8（含 BOM）或 GB18030 CSV，要求平衡电压和时间表头，每颗连续四行，3–8 颗；每次电压和仪器电荷保留可编辑。
- 扭摆：按仪器 XLSX 固定单元格读取；质量 kg、尺寸 cm、两滑块惯量单位转换，保留三次尺寸读数。
- 波尔共振：只读取“学生实验数据”工作表，识别表头及合并单元格旁的值，支持移动列、续接自由周期列和独立数量的阻尼/受迫表；优先原始测量表，拒绝不完整行和不连续序号。

XLSX 公式读取已有缓存值，不在服务端重新计算。未保存缓存的公式单元格必须由用户在电子表格软件中计算保存后上传。

图片解码依赖容器中的 ImageMagick/libheif，不依赖 Python。首帧、方向校正、缩放和 JPEG 输出规则见 [架构](architecture.md)。
