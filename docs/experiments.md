## 数值与显示

JSON 数字和字符串均直接解析十进制，保留原始读数文本。代数使用 `shopspring/decimal`，除法保留 60 位小数；平方根使用 256 位 big.Float 后转回十进制。log/atan2 边界沿用原实现的 float64 定义。数值大小与指数有界，错误不转成零继续计算。

此精度策略比旧 Python Decimal 的 28 位上下文更高，不宣称任意输入逐中间位一致。合成参考样本比较最终数值和图点；临界有效数字使用独立测试。参考常数与公式的修正见下方各实验说明。

不确定度首位为 1/2 保留两位，否则一位；结果末位对齐不确定度。最终输出使用半偶舍入；先完成计算再修约。很大/很小结果可使用共享科学计数指数；原始表格读数不按结果精度改写。一般过程字段采用六位有效数字，过程字段和零不确定度结果的尾零可能与 Python 的文本表示不同。

## 导入

- JSON 读数支持普通十进制、`5e-2`，以及 `5×10⁻²`、`5×10^-2` 形式的科学计数法（乘号可用 `×`、`x`、`X`、`*`，指数支持上标数字或 `^` 后的整数）。导入时后两种写法转换为 `e` 格式，保留系数的小数位和末尾零，例如 `5.00×10⁻²` 转为 `5.00e-2`；普通十进制与已有 `e/E` 文本保持原样。不接受附带单位或算式的读数，数值仍按字段标注的单位填写，不自动换算。
- 油滴：UTF-8（含 BOM）或 GB18030 CSV，要求平衡电压和时间表头，每颗连续四行，3–8 颗；每次电压和仪器电荷保留可编辑。
- 扭摆：按仪器 XLSX 固定单元格读取；质量 kg、尺寸 cm、两滑块惯量单位转换，保留三次尺寸读数。
- 波尔共振：只读取“学生实验数据”工作表，识别表头及合并单元格旁的值，支持移动列、续接自由周期列和独立数量的阻尼/受迫表；优先原始测量表，拒绝不完整行和不连续序号。

XLSX 公式读取已有缓存值，不在服务端重新计算。未保存缓存的公式单元格必须由用户在电子表格软件中计算保存后上传。

图片解码依赖容器中的 ImageMagick/libheif，不依赖 Python。首帧、方向校正、缩放和 JPEG 输出规则见 [架构](architecture.md)。

## 透镜位置读数

三种方法均按位置差的绝对值计算：u = |single_lens − single_object|，v = |single_image − single_lens|，L = |bessel_image − bessel_object|，D = |bessel_lens_small − bessel_lens_large|；分别使用 f = uv/(u+v)、f = (L²−D²)/(4L)、f = |auto_lens − auto_object|。每组读数可独立正向或反向排列，无需手动选择坐标方向；原有 `position_direction` 参数仍接受 1/−1，但不影响距离计算。拒绝零距离、透镜在物像屏之外或共轭法成大像位置远离物屏的输入。各方法均输出均值与 A 类标准不确定度，末端修约规则不变。

回归覆盖用户截图的 930 mm 反向读数，以及 x → 1200 − x、x → −x 的镜像坐标；三种方法的各次距离、焦距、均值与不确定度应与正向样本一致，原始坐标文本保留。

## 密立根油滴参考公式

“实验原理”按用户提供的讲义截图转写 3.1、表 8.3.1 及其下方的常数/近似说明、4.2，保留式 (8.3.1)–(8.3.13)、(8.3.17)–(8.3.29)。图 8.3.1 与图 8.3.5 从对应截图裁切，分别存为 `figures/millikan-static-source.png`、`figures/millikan-charge-axis-source.png`；不纳入 3.2 动态法和仪器结构章节。保留讲义的历史记法：3.1 正文 b=8.22×10⁻³，参数表 b=8.23×10⁻³；4.2 式 (8.3.21) 的偏差以 e₀ 为基准。此次仅改原理叙述，实际计算仍使用既定系数和第 7 节以样本均值为中心的反向验证不确定度，公认值仍为 1.602176634×10⁻¹⁹ C。

报告“7 数据记录与处理”采用讲义 7.1 静态平衡法：模糊统计、反向验证、Q–n 图解和最小二乘四部分；不含动态法。表 8.3.2 固定八行，列为 m、U、t₁–t₄、平均时间、Qᵢ（×10⁻¹⁹ C）、nᵢ，无 t₅ 或额外 eᵢ 列。下降八格对应 1.6 mm，保留 3–8 颗输入兼容性，未使用的行留空。

模糊统计部分展示以公认值辅助取整 nᵢ、固定 nᵢ 后求近似公约数的过程，采用与过原点最小二乘相同的估计；报告明确此方法依赖公认值，不能作为独立验证。图解采用带截距拟合，并输出斜率、截距、百分差及实际散点图。反向验证与最小二乘按讲义 Uₑ=t√[Σ(Qᵢ/nᵢ−e)²/(m(m−1))] 输出扩展不确定度，反向验证的 e 为各 Qᵢ/nᵢ 的均值；默认双侧 95% 置信水平，m=3–8 的 t 分别为 4.303、3.182、2.776、2.571、2.447、2.365。旧标准不确定度字段继续保留，图解的斜率误差仍为拟合标准不确定度。

原始数据页按仪器 CSV 的四列（当前电压Uc(V)、平衡电压U(V)、时间t(s)、电荷量(C)）逐行排版，保留小数末尾零和空白电荷量，不增加油滴/次数列，不用计算值填补仪器电荷量。报告展示时，若仪器电荷量整列为空则隐藏该列，仅显示当前电压、平衡电压和时间；任一行有电荷量读数则保留四列，底层原始记录不变。仪器文件的连写表头拆为四列；手动修改后的表格作为最终原始记录。兼容旧六列导入记录。

按用户提供讲义式 (8.3.19)，q = 0.928×10⁻¹⁴ / {U [t (1 + 0.0226√t)]^(3/2)} C，t 为同一颗油滴四次下降时间的均值，U 为四次平衡电压的均值。时间 t 与修正项一起取 3/2 次方；旧实现漏掉 √t，导致电荷量偏大。整数倍数、反向验证、图解拟合、过原点最小二乘及图点均按新电荷量重新计算。

参考常数：d = 5×10⁻³ m，l = 1.6×10⁻³ m，η = 1.83×10⁻⁵ kg/(m·s)，ρ₁ = 981 kg/m³，ρ₂ = 1.2928 kg/m³，g = 9.794 m/s²，b = 8.23×10⁻³ m·Pa，p = 1.01325×10⁵ Pa。沿用讲义的近似系数 k = 0.928×10⁻¹⁴、k′ = 0.0226。

独立 Decimal 60 位参考样本：(t/s, U/V, q/C) = (4, 100, 1.0855726362588707148×10⁻¹⁷)、(16, 200, 6.3673576172547516812×10⁻¹⁹)、(25, 300, 2.1075309540952215386×10⁻¹⁹)。`server/testdata/calculations.json` 的油滴预期值已同步更新；历史归档保留原语境。

### 扭摆末端有效数字（仅本实验）

按用户提供的评分标准，所有转动惯量（理论值、实验值、载物圆盘、滑块组合及 I₅）和弹簧扭转常数 K 的最终显示保留四位有效数字，并保留必要尾零；实验值相对理论值的百分误差保留两位有效数字（零误差显示 0）。例如 I = 0.00013 显示为 0.0001300，I₅ = 8.139×10⁻⁵ 仍为 8.139×10⁻⁵，27.81% 显示 28%，0.0786443% 显示 0.079%，386.1% 显示 390%（修约到十位）。

采用十进制半偶舍入，只在生成结果字段时从完整计算值修约一次。K、I₄、I₅、各周期等在后续惯量、误差和图点计算中仍使用未修约值；即使四位有效数字显示的实验值与理论值相同，百分误差也可能不为零。原始读数、单位换算、周期、尺寸、质量及不确定度规则不变；扭摆的最终 K/I 不再由不确定度决定末位。图点继续保留原有过程坐标精度，其他七种实验的修约规则不变。
